# Отчет по практической работе: Одномерные массивы

## Выполненные задачи

**1. Баллы за задания (scores.cpp)**
Реализована программа, которая запрашивает четыре целочисленных значения, сохраняет их в массив и позволяет получить оценку по введенному номеру.
В программе реализована проверка ввода номера через условие `if`, чтобы предотвратить обращение к несуществующим индексам массива (защита от выхода за границы).

**2. Температура за шесть часов (temperatures.cpp)**
Написана программа для анализа шести измерений температуры.
Она последовательно обходит массив в цикле, вычисляя сумму всех значений, находя минимальную и максимальную температуру, а также подсчитывая количество положительных измерений. Среднее арифметическое рассчитывается с приведением типов и выводится с двумя знаками после запятой с помощью библиотеки `<iomanip>`. Для корректной работы минимума и максимума за начальные значения берутся элементы из первой ячейки массива.

**3. Поиск и замена элемента (inventory.cpp)**
Создана программа учета остатков товара.
В ней реализован алгоритм линейного поиска первого совпадения по заданному числу (с использованием флага и оператора `break`). Также реализован механизм замены значения по номеру ячейки с комплексной проверкой корректности введенного индекса и нового значения. В качестве дополнительного задания реализован вывод элементов массива в обратном порядке.
