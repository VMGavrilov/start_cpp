# Практическая работа: Калькулятор с enum class

**ФИО:** Гаврилов Владислав Михайлович  
**Группа:** РПО 25/1  
**Дисциплина:** Основы программирования на C++

## Описание работы

В рамках практической работы разработан консольный калькулятор, выполняющий четыре арифметические операции над двумя числами: сложение, вычитание, умножение и деление.  

В ходе выполнения отработаны следующие навыки:
- использование `enum class` с явным заданием базового типа (`char`);
- приведение пользовательского ввода к типу перечисления через `static_cast`;
- организация последовательного ввода данных с понятными приглашениями;
- реализация логики выбора операции через `switch`;
- обработка ошибочных ситуаций (деление на ноль, неизвестная операция).
