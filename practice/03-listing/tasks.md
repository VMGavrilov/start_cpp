# Техническое задание: Консольный калькулятор на C++

## 1. Цель работы

Разработать консольное приложение «Калькулятор», выполняющее четыре арифметические
операции над двумя введёнными пользователем числами. Работа закрепляет навыки
использования перечислений (`enum class`), приведения типов, условной логики
и ввода/вывода через стандартные потоки.

## 2. Требования к функциональности

### 2.1. Ввод данных

Программа должна последовательно запрашивать у пользователя:

1. Первое число (вещественное).
2. Символ операции: один из `+`, `-`, `*`, `/`.
3. Второе число (вещественное).

Требования:
- ввод выполнять через стандартный поток `std::cin`;
- числа хранить в переменных типа `double` для поддержки дробных значений;
- символ операции хранить в переменной типа `char`.

### 2.2. Вычисления

- Программа должна выполнять четыре операции: сложение, вычитание, умножение, деление.
- Операции должны быть представлены перечислением `enum class Operation` с базовым
  типом `char`, значения которого соответствуют символам операций.
- Выбор операции должен выполняться оператором `switch` по значению перечисления;
  каждому варианту соответствует отдельный `case`.

### 2.3. Вывод результата

- При успешном вычислении программа выводит строку формата:
  `число операция число = результат`
  (например: `5 + 5 = 10`, `7 / 2 = 3.5`).
- Вывод выполнять через стандартный поток `std::cout`.
