## Выполненные задачи

### 1. Хранение операций через enum class

Для представления арифметических операций использовано перечисление `Operation` с базовым типом `char`. Значения перечисления напрямую соответствуют символам операций: `+`, `-`, `*`, `/`.  

Такой подход позволяет хранить операцию как осмысленное значение, а не как «магическое» число или строку, и при этом удобно сопоставлять её с введённым пользователем символом.

### 2. Организация пользовательского ввода

Программа запрашивает у пользователя данные в три шага:
1. Первое число.
2. Символ операции.
3. Второе число.

Числа хранятся в переменных типа `double`, что обеспечивает корректную работу с дробными результатами, особенно при делении. Последовательный ввод делает интерфейс понятным и снижает вероятность ошибок при вводе выражения.

### 3. Вычисление результата через switch

Выбор операции реализован через оператор `switch` по значению перечисления `Operation`. Для каждой операции предусмотрен отдельный `case`, выполняющий соответствующее арифметическое действие.  

Результат выводится в формате: `число операция число = результат`, что делает вывод наглядным и читаемым.

### 4. Обработка ошибочных ситуаций

Реализована защита от двух типов некорректных ситуаций:

- **Деление на ноль.** Перед выполнением деления проверяется, что второй операнд не равен нулю. При попытке деления на ноль выводится сообщение об ошибке, а результат не вычисляется.
- **Неизвестная операция.** Если пользователь вводит символ, не соответствующий ни одной из операций, срабатывает ветка `default` в `switch`, и программа сообщает о некорректной операции. В обоих случаях итоговая строка с результатом не выводится.
